### 记忆管理 (.claude/memory/)

使用你的内置文件读写工具来编辑你的记忆。遵守以下 `.claude/memory/` 目录的读写规范：

# `permanent_memory.md`

- 这个文件需要是 memory 文件夹下固定且唯一的，记录一些很重要、每次都会用到的、用于长期记忆的备忘录内容

# `YYYY-MM-DD-HH-mm.md` 记录

- 文件名必须按照当前时间格式命名（如：`2026-08-20-22-30.md`）。
- 总结这一次做了什么、你的观察、值得记录的重要的东西。
- 在开始和用户讲解前，回顾前几次的记录。

所有记忆文件的路径均为相对路径 `.claude/memory/<filename>`。写入前若目录不存在，请先创建这个目录。
